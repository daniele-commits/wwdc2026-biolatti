Xcode 27: ecosistema di plugin aperti con Figma e GitHub al lancio, protocollo agent-client

Apple ha aperto Xcode 27 a plugin di terze parti tramite un protocollo agent-client che supporta skills, MCP tools e agenti AI. Figma e GitHub saranno disponibili al lancio, mentre Anthropic, OpenAI e Google porteranno i loro agenti di coding nell'IDE.

Pubblicato: 2026-06-10T17:03:54.008728+02:00 Area tematica: Sviluppatori

Un IDE che si apre all'esterno

Xcode è sempre stato un ambiente tendenzialmente chiuso, con estensibilitá limitata rispetto a concorrenti come VS Code. Al WWDC 2026 Apple ha cambiato rotta: Xcode 27 introduce un protocollo agent-client che permette agli sviluppatori di estendere l'IDE tramite plugin che possono portare skills personalizzate, strumenti MCP (Model Context Protocol) e agenti AI di terze parti. Al momento del lancio, Figma e GitHub avranno giá plugin disponibili, rispettivamente per l'integrazione dei file di design e per la gestione del codice sorgente.

Anthropic, OpenAI e Google nell'IDE

La parte piú rilevante per lo sviluppo AI-assistito è l'accordo con i tre principali provider di modelli. Secondo MacRumors e Let's Data Science, Apple sta lavorando con Anthropic, OpenAI e Google per portare i loro agenti di coding direttamente in Xcode. Le conversazioni con questi agenti si comportano come file all'interno dell'IDE: possono eseguire test, usare i Playground e controllare un'app in esecuzione end-to-end. Questo posiziona Xcode 27 come ambiente integrato in cui l'agente AI ha accesso completo al contesto del progetto — build system, simulatore, debugging — senza uscire dall'IDE.
