Image Playground now generates wallpapers and Contact Posters with AI

With iOS 27 and macOS Golden Gate, Image Playground expands beyond standalone images: it can now create custom wallpapers and Contact Posters, and new APIs let developers integrate the same capabilities into their own apps.

Published: 2026-06-09T00:03:47.381405+02:00 Topic area: Apple Intelligence and Siri

Beyond the standalone image

When Image Playground arrived with iOS 18, its practical utility was limited: it generated stylized images that then had to be manually exported. With iOS 27 and macOS Golden Gate 27, Apple has significantly broadened the use cases. Among the new outputs are custom wallpapers and Contact Poster creation — the personalized screen shown when receiving a call from a contact. This is reported by 9to5Mac and TechRadar.

APIs for developers

Alongside this, Apple is introducing new Image Playground APIs that allow developers to integrate the same image-generation capabilities into their own applications. This is not a minor detail: it means third-party apps can offer AI image creation with the same quality and on-device privacy guarantees Apple provides in its native app, without building their own model or relying on external cloud services.

The photo-realistic model as the central element

As already noted for Image Playground 2 more broadly, the new photo-realistic style also changes this feature's profile. A wallpaper generated in an illustrative style was a niche product; a photo-realistic wallpaper generated from a text description or an existing photo has a much wider audience.
